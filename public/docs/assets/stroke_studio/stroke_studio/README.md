# Stroke Studio

Place this folder in a Field workspace and open the `stroke_studio` document. Run **Stroke types**,
launch **Stroke renderer**, then launch **Stroke studio**. Choose **View** in **Scene and views**
to see the diagnostic passes. Press **C** in the native render window to clear the strokes.

The renderer requires Vulkan task and mesh shaders. The window is 1600 × 1000. The full paint
and composite targets are 3840 × 2400.
