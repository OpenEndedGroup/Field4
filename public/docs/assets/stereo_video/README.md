# Stereo-video source media and captures

`stereo-demo.mkv` is original calibration media, generated analytically by
`tools/generate_stereo_video_demo.py`: two pinhole views, 64 mm apart, of three moving spheres
and a floor grid. It is a 3 s loop, full SBS 1280 x 360, 24 fps, FFV1 yuv420p10le with
BT.709 matrix/range metadata. It uses sRGB-encoded SDR RGB values before YUV conversion.
The source is provided under the repository's license. Rebuild with:

```
uv run --with numpy python tools/generate_stereo_video_demo.py
```

`player.png` and `playback.mp4` are generated by the documentation runner from the real
Vulkan player, using the `docs_capture/video_one_native.yaml` and `video_one_motion.yaml`
operation transcripts. They are not source-media screenshots substituted for player output.
