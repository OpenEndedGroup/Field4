# Gallery layout

These five canvas boxes are labels for code, not output viewports. Keep them compact:
480 × 100, stacked from (60, 60) with 140 pixels between starting positions.
The examples set viewer and image dimensions separately through `width`, `height`,
`cellWidth` and `MeshView`. Do not enlarge the canvas boxes to fit those outputs.

Preserve the box IDs, code and connections when changing the layout. Use Field's
document reader/writer for the saved EDN.
