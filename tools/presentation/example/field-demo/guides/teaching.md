# From slides to a live document

This is the moment to stop presenting a picture of an editor. The audience is looking at the real Field document, with the same canvas, source, outputs and guide system you use while teaching.

1. Select **Live Field** and change the sentence in its `code` property. Run the box; the audience sees the edit and output in place.
2. Try **Start interactive guide** in the controller, then **Guide next**. The real Field guide selects boxes and opens code in the audience document.
3. In the presenter controls, run **reveal_wave**. The saved macro creates and runs another box in this document.
4. Select the new box, change the frequency or colour, and run it again. Return to the next cue when the discussion is done.

The macro is in `field-demo/macros/reveal_wave.yaml`. This guide and the document are ordinary files in the presentation repository.
