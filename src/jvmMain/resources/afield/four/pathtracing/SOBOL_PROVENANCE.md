# Sobol direction words

`sobol-100x32.bin` contains 100 dimensions x 32 unsigned 32-bit direction words,
dimension-major and little-endian. The shader Gray-codes its sample index and XORs
the selected direction words before applying a pixel/dimension-specific hierarchical scramble.

Generated by `tools/generate_pathtrace_sobol.py` using SciPy 1.17.1's unscrambled
`scipy.stats.qmc.Sobol(d=100, bits=32)._sv`. This matrix uses the Joe–Kuo direction
numbers, search criterion 6. SciPy is not a runtime dependency of Field or the tracer.

- Matrix SHA-256: `60dca4ace8ac3a62deab4021c7a82f576584911f3f1465c21b14e9a054f655ad`
- SciPy documentation: https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.qmc.Sobol.html
- Joe–Kuo data and construction: https://web.maths.unsw.edu.au/~fkuo/sobol/
- SciPy source release: https://github.com/scipy/scipy/tree/v1.17.1/scipy/stats
- SciPy's BSD license is retained in `SOBOL_LICENSE.txt`.

Dimensions 0–1 sample the pixel, 2–97 sample up to twelve bounces, and 98–99 sample
the thin lens. The first 98 dimensions are unchanged from the original pinhole renderer.

Regenerate from the checkout root:

```sh
uv run --with scipy==1.17.1 python tools/generate_pathtrace_sobol.py
```
