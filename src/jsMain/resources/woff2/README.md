# Iosevka webfonts

These are the normal-width WOFF2 faces from the official Iosevka 34.7.0
`PkgWebFont-Unhinted-Iosevka` release archive. Field intentionally does not
ship or register the Extended faces.

Source: https://github.com/be5invis/Iosevka/releases/tag/v34.7.0
