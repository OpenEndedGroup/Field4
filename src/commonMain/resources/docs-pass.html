2 · Drain the queue 

        

        

            
            
            
            
        

        

            
            
            
        

        
One agent per page, in the pass's worktree. Stop after current pages lets running agents finish and starts no more; Stop now ends them. Either way, whatever they recorded is kept and every other note stays in the queue.

        

    


    

        
3 · Handoffs 

        
Work an agent judged too big for a page, worked through in batches, in order: decisions first, because they change what the navigation work is; navigation next, because it moves the pages captures and code land on. Start session makes a worktree for one batch with a brief listing its handoffs, and gives you the claude command to run there. A blocking handoff holds its page's notes until it is closed.

        

        

    


    

        
4 · Changes 

        
Against the commit the pass started from. Discarding a file also puts back in the queue every note its edit claimed to resolve.

        

    


    

        
5 · Rebuild, commit, land

        

            
            
        

        

        

            
            
        

        
Commit runs the repository's pre-commit guard (several minutes). Land merges main into the pass branch if it has moved on, then fast-forwards main in this checkout. Nothing is pushed.
