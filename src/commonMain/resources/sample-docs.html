🎯 Field Documentation API

This is a sample documentation page demonstrating the Field iframe API. When loaded in Field's documentation iframe mode, this page can control Field through the FieldAPI object.

📚 API Reference

Box Control

  • FieldAPI.executeBox(uid, code) - Execute code in a specific box
  • FieldAPI.beginBoxes(uids) - Launch/start boxes
  • FieldAPI.endBoxes(uids) - Stop running boxes

Selection & Navigation

  • FieldAPI.selectBoxes(uids, add) - Select boxes (add=true to add to selection)
  • FieldAPI.navigateToBox(uid, select) - Scroll to and optionally select a box
  • FieldAPI.getSelection(callback) - Get current selection info

Editor Control

  • FieldAPI.switchToProperty(property) - Switch to editing a property (code, vertex, fragment, etc.)
  • FieldAPI.switchToEditor() - Return to Monaco editor

Box Management

  • FieldAPI.createBox(options) - Create a new box
  • FieldAPI.runCommand(command, args) - Run a Field command

📖 Usage Example

// Check if API is available
if (window.FieldAPI) {
    // Get current selection
    FieldAPI.getSelection((selection) => {
        console.log('Selected boxes:', selection.boxes);
        console.log('Current property:', selection.property);
        
        // Execute code in first selected box
        if (selection.boxes.length > 0) {
            const uid = selection.boxes[0].uid;
            FieldAPI.executeBox(uid, 'println("Hello from docs!")');
        }
    });
    
    // Switch to fragment shader property
    FieldAPI.switchToProperty('fragment');
    
    // Return to editor
    FieldAPI.switchToEditor();
}
