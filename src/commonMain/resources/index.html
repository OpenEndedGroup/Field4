use the url to open a document, e.g. http://localhost:9091/index.html?file=helloWorld

n creates a new box
(select) selecting a box shows an editor for the code inside it

F1 opens a searchable command menu for everything else

alt-0 executes all code in a box
alt-click launches a box
alt-up also launches a box
alt-down stops a launched box
alt-return executes the current line / block of code
alt-drag executes multiple boxes in a "strum"

esc-esc clear output annotations from the editor

command-space opens autocomplete

g groups two selected boxes
u ungroups boxes
