use the url to open a document, e.g. http://localhost:9092/index.html?file=helloWorld

N creates a new box
(select) selecting a box shows an editor for the code inside it

F1 opens a searchable command menu for everything else (align, route, etc.)
⇧ ⇧ double tap opens box menu (anywhere palette)

⌥ 0 executes all code in a box
⌥ click launches a box
⌥ ↑ also launches a box
⌥ ↓ stops a launched box
⌥ ↩ executes the current line / block of code
⌥ drag executes multiple boxes in a "strum"

⎋ ⎋ clear output annotations from the editor

⌘ ␣ opens autocomplete

⌃/⌘ T insert from workspace (templates)

⌃/⌘ / toggle docs iframe (docs & editor)

G groups two selected boxes
U ungroups boxes

⇧ ⌃/⌘ F1-F9 save bookmark 1-9
⇧ F1-F9 restore bookmark 1-9
