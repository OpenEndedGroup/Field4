Basics
N creates a new box
(select) selecting a box shows an editor for the code inside it
Search and Help
? shows this help card
P opens the searchable command palette
P opens anything: boxes, properties, commands, and document text
double tap opens anything from the canvas
double tap and hold for spatial navigation; use arrow keys to move between boxes
Run
0 executes all code in a box
click launches a box
Up also launches a box
Up continues a launched box
Down stops a launched box
Enter executes the current line / block of code
drag executes multiple boxes in a "strum"
Editor
Esc Esc clear newest output annotation from the current editor
Esc Esc Esc clear all outputs from the current editor
Space opens autocomplete
T insert from workspace (templates)
/ toggle docs iframe (docs & editor)
Graph
G groups two selected boxes
U ungroups boxes
F1-F9 save bookmark 1-9
F1-F9 restore bookmark 1-9
Every shortcut here is yours to change: run Open Keybindings, or edit ~/.afield/keybindings.yaml — it is watched, so changes apply as you save.
