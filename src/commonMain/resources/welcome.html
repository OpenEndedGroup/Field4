    Nothing is required. LWJGL carries MoltenVK inside its jar, so graphics runs on a fresh Mac.
    
                            
    Recommended: the LunarG Vulkan SDK. On Apple silicon with macOS 26 it brings KosmicKrisp, the conformant Vulkan driver Field uses by default wherever it can run. It also adds the validation layers (Field turns them on to report shader and API mistakes), vulkaninfo and slangc.
    
                            
      
                                
    1. Download the macOS SDK from vulkan.lunarg.com and run its installer.
      2. 
                                
    2. Keep the default location, ~/VulkanSDK/<version>. Field uses the newest one there. System Global Installation is not needed. From SDK 1.4.363 KosmicKrisp is part of the core install; older SDKs list it as KosmicKrisp (Vulkan on Metal), to tick.
      3. 
                                
    3. Restart Field. It chooses its loader at startup.
      4. 
                            
    
                            
    From a terminal, with the SDK zip unpacked:
    
                            
    vulkansdk-macOS-<v>.app/Contents/MacOS/vulkansdk-macOS-<v> --root ~/VulkanSDK/<v> --accept-licenses --default-answer --confirm-command install com.lunarg.vulkan.core
    
                            
    To use MoltenVK instead, as the IOSurface video streaming and browser-surface features still need:
    
                            
    AFIELD_VULKAN_DRIVER=moltenvk ./field.sh
    
                        
    
                        
    
                            
    Required: a current GPU driver from NVIDIA, AMD or Intel. It installs the Vulkan runtime (vulkan-1.dll). Drivers from Windows Update sometimes leave it out, so get the vendor's.
    
                            
    Recommended: the LunarG Vulkan SDK, for the validation layers and vulkaninfo:
    
                            
    winget install -e --id KhronosGroup.VulkanSDK
    
                            
    Or use the installer from vulkan.lunarg.com. Then open a new terminal and restart Field.
    
                        
    
                        
    
                            
    Required: the Vulkan loader and a driver for your GPU. With Mesa (AMD, Intel):
    
                            
    sudo apt install libvulkan1 mesa-vulkan-drivers vulkan-tools vulkan-validationlayers
    
                            
    sudo dnf install vulkan-loader mesa-vulkan-drivers vulkan-tools vulkan-validation-layers
    
                            
    sudo pacman -S vulkan-icd-loader vulkan-tools vulkan-validation-layers vulkan-radeon vulkan-intel
    
                            
    For NVIDIA, the proprietary driver supplies the Vulkan driver: sudo ubuntu-drivers install on Ubuntu, nvidia-utils on Arch. Install the loader and validation packages above as well.
    
                            
    vulkaninfo --summary should then list your GPU. Restart Field.
