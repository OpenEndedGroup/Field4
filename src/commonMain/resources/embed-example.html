📖 Embedding Field4 Documentation

About This Demo

This page demonstrates how to embed the Field4 offline viewer in your own documentation website. The viewer runs in an iframe and provides an interactive way to showcase Field projects without requiring users to install anything.

Features:

  • Fully contained - no backend required
  • Read-only documentation mode
  • Syntax-highlighted code viewing
  • Works in any modern browser
  • Can be embedded in tutorials, courses, and documentation

How to Embed

Add this code to your webpage:

<iframe 
  src="offline.html?file=path/to/your/file.edn" 
  width="100%" 
  height="600" 
  frameborder="0">
</iframe>

Customization Options

You can customize the viewer by:

  • Adjusting iframe dimensions to fit your layout
  • Modifying the viewer's CSS (see offline.html)
  • Adding navigation controls like the example above
  • Creating a gallery of multiple examples

Best Practices

  • Keep EDN files organized in a clear directory structure
  • Provide context and descriptions around embedded viewers
  • Use meaningful file names that describe the example
  • Consider adding navigation between related examples
  • Test on mobile devices - the viewer is responsive
