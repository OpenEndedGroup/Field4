# Function conversation — start here

This is a blank starting point: three zero-valued channels over one hour, a source
box, and eight document-defined AI4 tools. It contains no saved conversation,
checked revision, or finished musical gesture.

1. Open this document in Field.
2. Run **Observation tools — run first**. It checks the blank source and displays
   three flat lines.
3. Select **function_source** and press **command/ctrl-4**.
4. Try:

> Let's start with a 3d channel function, lasting an hour — sine waves from 0 to 1
> at around 0.2 Hz, drifting slowly in and out of phase.

Here “3d” means x, y and z as functions of time. The drifting phase rate is an
artistic choice for the conversation to settle. Accepted Kotlin appears in the
source box; the Plotly overview follows it. Zoom into about 25 seconds to see the
individual cycles. Subsequent edits create revisions in this document.

The separate **function_conversation_example** preserves the developed one-hour
composition, its saved conversations and its checked revisions. The public guide
is **Talking a function into existence** (function_conversation.md in Field's docs).
[Tool contract](guides/working.md).

When switching between the starter and the worked example in one Field session,
rerun the tools box in the document you want to chat with. The most recently
registered handlers belong to that document.
