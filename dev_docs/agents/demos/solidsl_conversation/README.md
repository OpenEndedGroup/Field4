# SolidSL conversation — starter

The blank starting point for `public/docs/solid_conversation.md`: a SolidSL window root and one
SolidSL study box, `solid_source`, whose Kotlin is a sphere. Opening the document opens the window,
which turns the solid, and checks the source in as the study's first revision. Select the study box
and open its AI4 chat (Cmd+4) to describe a solid. `metadata.edn` is written by
`tools/solidsl_conversation_documents.py` from the box files beside it.
