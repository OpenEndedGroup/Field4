## Changes

- Faust uses the stereo render's `wav` helper. Onset measurement distinguishes signed early/late
  attacks from absent or ambiguous transitions, excludes the initial attack without preceding
  silence, and claims exact timing only when all eligible measurements agree. Steal diagnostics
  print both the normalized jump and its ratio to the settled baseline, with the correct meaning.
- The live OSC fader opts into run ownership; the port's shared server remains persistent.
  Other examples retain their deliberate persistent registration behavior. Prose handoff
  `c1b480b7` explains the distinction in the surrounding page.
- Three slice examples use `sampleSlices`, copying contour data inside its bounded callback.
  Fill rules and integration math stay explicit. The kkC diagnostic deliberately uses
  `toSolid(check = false)` so it can report inward winding rather than failing before its table.
- Syphon comments explain the approved named cache: reuse an open client, recreate a closed one.
  Automatic stop-time closing would contradict the user's adjusted decision.
- Every RectSL wrapper uses `worldToClip`, the diagnostic `program` getter, and the Unit loop
  convention. The Kotlin-escape compiler is owned by its run. The metadata fallback was refreshed
  with Field's persistence codec; its stale 14-box Markdown mirror was regenerated for 39 boxes.

Imports and ktfmt were applied to all Kotlin states. Markdown states were extracted/restored
through the checked formatter helper; gallery paths were expanded explicitly because directory
arguments are unsupported. The explicit collection-literal audit passed over 44 files. Authored
fragment boundaries and reset assignments remain intact. No library API changes.
