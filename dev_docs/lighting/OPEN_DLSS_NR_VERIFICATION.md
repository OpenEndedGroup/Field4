## Limits

Linux mono rendering is verified. The split Vulkan12 OpenXR feature merge is implemented but no
working OpenXR runtime was available to exercise it. Other operating systems report unavailable.
Temporal depth validation is conservative; this is an experimental creative image-processing path,
not a demonstrated general video-restoration solution. Arbitrary video requires supplied real motion.
Premultiplied alpha needs a wrapper. Controls change history validity; grading after inference does not.

The native adapter serializes its hidden volk dispatch and reloads the owning device at each C ABI
entry, including teardown. It shares model/kernel caches by device, keeps graph commands/descriptors
immutable while frames are in flight, releases graph descriptor sets on retirement, and never waits
for device idle during adopted-context destruction. Multiple simultaneous passes on one device are
verified; concurrent distinct renderers/devices are isolated in code but not separately stress-tested.
